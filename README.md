# Jose Madrid Salsa Presents: Battle for the Salsa King (3D brawler)

A Three.js last-one-standing brawler for 2 to 8 fighters, with local and online play.

- `index.html` is the whole game in one file. Open it in a browser, or serve this branch as a static site.
- `source/` holds the readable source; `source/README.md` explains controls, online rooms and how to rebuild.

This branch is unrelated to the Arena Fundraiser project on `main`.
